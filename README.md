# AWS Cloud Services: Mission 2

Hands-on project covering storage, database and serverless computing on AWS (Asia Pacific, Sydney).

## Services used
- Amazon S3: object storage (image-s3-demo-bucket)
- Amazon DynamoDB: NoSQL database (students table)
- AWS Lambda: serverless function (hello-function, Python)

## Files
- report.pdf: full project report
- architecture-diagram.png: architecture diagram
- lambda_function.py: Lambda function code
- screenshots/: proof of each service working

## Architecture
User -> AWS Lambda -> Amazon S3 and Amazon DynamoDB
